# International Management Test 1

Static practice exam for International Management, with 50 questions per exam, answer feedback in Russian and English, and responsive desktop and mobile layouts.

## Run locally

Open `index.html` in a browser. No installation or build step is required.

## Deploy

The Vercel project is connected to this repository. Commits to `main` trigger production deployments.

- Framework preset: Other
- Build command: none
- Output directory: repository root (`.`)

Production: https://international-management-test-1.vercel.app
